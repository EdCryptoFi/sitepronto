FLUXO EDICAO DE SITE (ADMIN)
-----------------------------
1. Cliente solicita edicao (WhatsApp/email)
2. Admin acessa /admin/briefings -> clica "Editar site" no briefing do cliente
3. /admin/editor/[id] carrega: template base (do segmento) + editor_content salvo
4. Admin edita via drag-and-drop (Craft.js canvas)
5. "Salvar" -> POST /api/admin/save-editor -> editor_content JSONB -> Supabase
6. "Publicar" -> dispara job deploy [futuro: BullMQ -> Gemini -> sub-dominio]

FLUXO PRINCIPAL (ATUAL)
-----------------------
1. /quiz -> /quiz/etapa-2 -> /quiz/etapa-3 (estado via quiz-context + auto-save)
2. /quiz/etapa-3 CTA "Publicar" -> POST /api/checkout
3. /api/checkout -> insertBriefing (Supabase) + createPaymentPreference (MP)
4. redirect para MP init_point
5. MP confirma -> back_url /success ou /failure
6. MP notifica -> POST /api/webhook/mp -> valida HMAC -> updatePaymentStatus
